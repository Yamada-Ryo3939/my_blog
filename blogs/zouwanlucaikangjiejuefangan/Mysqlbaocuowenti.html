Windows中连接数据库提示ERROR 1045

Yves2026/3/3技术学习踩坑解决方案

不知道为啥上午还能用的数据库，下午发现MySQL8.0登录时报错ERROR 1045 (28000): Access denied for user 'root'@'localhost' (using password: YES)，搞了好久才弄清楚原因，这个报错有很多种触发方法，这里只介绍我自己的情况，也许是电脑更新升级导致的。

这个报错提醒出现的可能性有几种，这里罗列一下我自己知道的： 1️⃣同时安装了MySQL5.6和MySQL8.0，导致登录时出现冲突。 2️⃣MySQL8.0默认安装时会设置一个随机密码，而不是我们常用的123456。 3️⃣单纯记错了。 4️⃣电脑升级系统导致的不明原因。 5️⃣检查MySQL服务是否启动。

1.检查用户名和密码

确保你的用户名和密码确实是正确的，特别是以下几点：

1️⃣ MySQL是大小写敏感的，一定要确保用户名和密码没有输错；

2️⃣输入时不存在空格，输入空格会导致登陆失败。同时检查cv操作时有没有把^C或^V操作输入进去。

2.使用正确的主机名

确保你在连接时使用的是localhost，如果是本地连接确保没有使用其他主机名或者IP地址。

3.重置root密码

1️⃣用管理员身份打开命令提示符，停止MySQL服务：

net stop mysql

除了这个方法，也可以打开win+R键打开服务窗口，找到MySQL服务，点击停止。这个方法也可以查看自己是否安装了两个版本的MySQL。

2️⃣然后输入如下操作，是为了跳过权限验证，这样下一步就可以跳过登录环节直接改密码了：

mysqld --console --skip-grant-tables --shared-memory

3️⃣用管理员身份打开新的命令提示符，注意，**上一个打开的窗口不要关闭，**然后在新窗口输入：

mysql
flush privileges;

4️⃣然后就可以修改数据库密码了，如果是MySQL5.x版本的话，用如下语句：

set password for root@localhost = password('123456');

如果是MySQL8.x版本语句会不同：

ALTER USER 'root'@'localhost' IDENTIFIED BY '123456';

引号里的密码可以自定义。

5️⃣退出MySQL：

quit;

6️⃣关闭之前步骤2️⃣打开的窗口，在退出MySQL的窗口里重启MySQL服务：

net start mysql

这个时候应该就可以登录了。
