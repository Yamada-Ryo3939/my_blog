Part 4.操控元素的基本方法

Yves2025/9/23技术学习Selenium自动化

上一节学会定位元素、选择元素之后，代码会返回WebElement对象，通过这个对象我们可以对元素进行操作。常见的操作有这些： 1️⃣点击元素 2️⃣在元素中输入字符串（通常针对输入框这样的元素） 3️⃣获取元素包含的信息，比如文本内容、元素属性

点击元素

点击元素其实就是直接调用WebElement对象的click()方法。但是要清楚，click方法一般是点击元素的中心点位置。拿按钮组件举例，有时候点击中心点会没反应，是因为1按钮组件的点击区域可能不是在中心点，而是在按钮的边界上，比如放在按钮的图标部分。 这个时候就需要点击span元素而不是button元素，这两个元素的中心点其实都是在button区域。偶尔会出现特殊情况。

输入框

在输入框中输入字符串也很简单，调用WebElement对象的send_keys()方法即可。

但是偶尔也会出现特殊情况，有时候重复测试会导致输入框中已经有了字符串，但是调用send_keys()方法输入新字符串时，需要把输入框中已有的内容清除才行。 示例清除代码如下：

element = wd.find_element(By.ID, "input-box")

element.clear()
element.send_keys("new text")

获取元素信息

获取元素文本内容

通过WebElement对象的 text 属性，可以获取元素展示在界面上的文本内容。

element = wd.find_element(By.ID, "element-id")
text = element.text
print(text)

获取元素属性

通过WebElement对象的 get_attribute() 方法，可以获取元素的属性值。 比如要获取元素属性class的值，就可以使用 element.get_attribute('class')

element = wd.find_element(By.ID, 'input_name')
print(element.get_attribute('class'))

执行完自动化代码，如果想关闭浏览器窗口可以调用WebDriver对象的 quit 方法，像这样 wd.quit()

获取整个元素对于的HTML代码

要获取整个元素对于的HTML内容，可以使用element.get_attribute('outerHTML') 如果只是想获取某个元素内部的HTML文本内容，可以使用element.get_attribute('innerHTML')

获取输入框里的文字

对于input输入框里的元素，要获取里面的文本，用text属性是不行的，这时可以使用element.get_attribute('value') 例：

element = wd.find_element(By.ID, 'input_name')
print(element.get_attribute('value')) #获取输入框中的文本

获取元素文本内容2

通过WebElement对象的text属性，可以获取元素展示在界面上的文本内容。

但是，有时候，元素的文本内容没有展示在界面上，或者没有完全完全展示在界面上。 这时，用WebElement对象的text属性，获取文本内容，就会有问题。

出现这种情况可以使用

element.get_attribute('innerText')

或者

element.get_attribute('textContent')

使用 innerText 和 textContent 的区别是，前者只显示元素可见文本内容，后者显示所有内容（包括display属性为none的部分）
